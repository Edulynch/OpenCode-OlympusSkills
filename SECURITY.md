# Security Policy

This policy covers this repository and its distributed skills.

## Report a vulnerability

Please do not disclose vulnerabilities, exploit details, or exposed credentials in a public issue, pull request, or discussion.

Use [GitHub's private vulnerability reporting](https://github.com/Edulynch/OpenCode-OlympusSkills/security/advisories/new) when available. Private reporting may not be enabled yet. If it is unavailable, contact the maintainer privately through the contact options on the [public maintainer profile](https://github.com/Edulynch).

Include the affected skill or file, the impact, steps to reproduce, and any relevant version or commit. Do not send live credentials; redact secrets and personal data from examples.

For non-sensitive bugs and feature requests, use the [public issue tracker](https://github.com/Edulynch/OpenCode-OlympusSkills/issues).
